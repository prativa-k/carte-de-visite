# Carte de visite (visiting card)

Carte-de-visite is a small personal website created as part of the application
process for the web development course at Simplon.

## Project Overview
The goal was to create a simple and clear personal presentation page using basic
web technologies.

## Technologies Used
- HTML
- CSS

## What I Practiced
- Clean and minimal design
- Page structure
- Responsive layout basics
- Presenting information clearly

## Status
Completed as part of the course application process.
